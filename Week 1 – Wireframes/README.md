# Food Delivery App – UX Wireframes

## Overview
This project presents low-fidelity wireframes for a food delivery mobile application.  
The goal was to design a clear, frictionless ordering flow from restaurant discovery to checkout.

## User Goal
Order food quickly with minimal steps and clear navigation.

## Core Flow
Home → Restaurant Menu → Item Details → Cart → Checkout → Order Confirmation

## Screens
1. Home / Restaurant Discovery
2. Restaurant Menu
3. Food Item Details
4. Cart
5. Checkout
6. Order Confirmation
