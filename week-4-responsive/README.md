# Week 4 – Responsive Landing Page

## Overview
Designed a fully responsive marketing landing page for the Food Delivery app across three breakpoints:

- Mobile (390px)
- Tablet (768px)
- Desktop (1440px)

## Key Focus Areas
- Mobile-first design approach
- Adaptive layout restructuring across breakpoints
- 12-column grid system for desktop
- Consistent spacing, typography, and visual hierarchy

## Sections Included
- Hero
- Features
- How It Works
- App Preview
- Call to Action
- Footer

## Outcome
The final result demonstrates responsive layout intelligence, ensuring the same content adapts effectively across screen sizes while maintaining usability and design consistency.
