# Week 3 – Interactive Prototype

## Overview
In Week 3, I transformed the high-fidelity UI screens into a fully clickable mobile prototype using Figma.

## Goal
Validate the complete food-ordering journey from discovery to order confirmation through real user interactions.

## Key Interactions
- Home → Restaurant Menu  
- Menu → Item Details  
- Add to Cart → Cart  
- Cart → Checkout  
- Place Order → Confirmation  
- Return to Home  

## Usability Testing
The prototype was tested on a real mobile device to ensure:
- Smooth navigation between screens  
- Clear call-to-action visibility  
- Fast task completion within seconds  

## Outcome
This stage confirmed that the design functions as a realistic, end-to-end mobile ordering experience rather than static UI screens.
